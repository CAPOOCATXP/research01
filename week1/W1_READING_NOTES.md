## 1. 读之前：三个二维三角不等式例子（已完成，可手算复核）

三角不等式的平实说法：**三角形任意一边都不超过另外两边之和。** 在最近邻问题里它这样用：
已知参考点 m 与中心 c（两者都在集合 M 里），对任意查询 q：

```
d(q, c) ≤ d(q, m) + d(m, c)          （三角不等式）
⟹  d(q, c) − d(m, c) ≤ d(q, m)       （移项）
```

因为 cell 里所有 m 都满足 `d(m,c) ≤ r`，所以 `d(q,c) − r` 是"q 到本 cell 任意参考点的距离"的**下界**。
而中心 c 自身就是参考点，所以 `d(q,c)` 是**上界**。对所有 cell 取下确界，得到
`L(q) ≤ s_M(q) ≤ U(q)`。

### 例子 1：下界**紧**（cell 只有一个点，且它在半径方向上）

```
M = { c = (0,0), m = (3,0) }        cell = {(3,0)}，r = d(m,c) = 3
q = (5,0)
```
- `d(q,c) = 5`，`d(q,m) = 2`
- `U = d(q,c) = 5`；`L = d(q,c) − r = 5 − 3 = 2`
- 真值 `s_M(q) = min(5, 2) = 2` → **L = s = 2，下界取等**
- 注意 `U = 5 > s = 2`：上界由中心决定，当最近参考点不是中心时上界就松。

### 例子 2：下界**松**（cell 里有两个方向的点）

```
M = { c = (0,0), m1 = (3,0), m2 = (0,3) }      r = max(3, 3) = 3
q = (4,4)
```
- `d(q,c) = √32 = 5.657` → `U = 5.657`
- `L = 5.657 − 3 = 2.657`
- 真值 `s_M(q) = min(5.657, √(1+16)=4.123, √(16+1)=4.123) = 4.123`
- **2.657 ≤ 4.123 ≤ 5.657**，区间宽度 3.0，而真值离下界还有 1.47 的余量
- 教训：**区间宽度由半径决定，而半径由 cell 里"离中心最远的那个点"决定**。高维特征里
  cell 一大会立刻把下界压到接近 0，这正是"为什么可能失败"的那条。

### 例子 3：多 cell 时区间跨阈值 → 必须升级

```
M = { c0 = (0,0), m1 = (1,0), c1 = (10,0), m3 = (9.5,0) }
cell0 = {(0,0), (1,0)} → r0 = 1        cell1 = {(10,0), (9.5,0)} → r1 = 0.5
q = (5,0)
```
- `d(q,c0) = 5`，`d(q,c1) = 5` → `U = min(5,5) = 5`
- `L = min(5 − 1, 5 − 0.5) = min(4, 4.5) = 4`
- 真值 `s_M(q) = min(5, 4, 5, 4.5) = 4` → **区间 [4, 5]，真值落在下界上**
- 若 `t = 3.5`：`L = 4 > 3.5` → 本地判 alarm；真值 4 > 3.5 → alarm ✅ 一致
- 若 `t = 4.5`：`L = 4 ≤ 4.5 < U = 5` → **区间跨阈值，必须升级**；升级后由完整库判 normal
- 教训：`L ≤ s ≤ U` 只保证"真值在区间内"，**不保证区间不给结论**。区间跨阈值时唯一的合法
  动作是升级查询（或返回未决），不能赌。

## 2. R7 Cover Trees for Nearest Neighbor —— 要点提纲（请与原文核对）

| 概念 | 我理解的要点 | 你要在原文里确认什么 |
|---|---|---|
| 问题定义 | 在度量空间 (S, d) 中做**精确**最近邻；不要求向量空间、不要求维度有限 | 论文对"度量"的假设有哪些（对称、正定、三角不等式） |
| 度量球 | 以 c 为心、r 为半径的球 B(c,r) 覆盖子树上所有点 | 覆盖不变式（invariant）具体怎么写 |
| 层级 | 第 i 层的节点之间距离 ≥ 2^i，父节点覆盖子节点 → 尺寸随 level 指数变化 | 为什么这样能保证树的深度是对数级 |
| 剪枝 | 用三角不等式：已知到某点的距离后，可推出一整棵子树的最小可能距离，达不到当前最优就整棵剪掉 | 剪枝条件的不等式推导 |
| 精确 vs 近似 | 剪枝给出的是**精确**答案的加速；近似搜索则是主动放弃一部分精度换速度 | 论文结论里"保证"到底保证什么 |
| 已知问题 | 原始渐进性证明存在缺口，Elkin & Kurlin 2023 [R10] 做了修正 | 修正后的复杂度假设（doubling dimension 等） |

**读完后应该能回答**：为什么"球内含参考点"能给出**距离下界**？以及"实证保证"与"算法保证"的差别
——前者是"我在这个有限测试集上没看到分歧"，后者是"对任意输入都不会分歧"。

## 3. R1 PatchCore —— 要点提纲（请与原文核对）

| 环节 | 我理解的要点 | 你要在原文里确认什么 |
|---|---|---|
| 特征 | 冻结的 ImageNet 预训练骨干（WRN-50），取中间层（layer2+layer3）特征 | 具体取哪几层、如何拼接、是否做局部邻域聚合（3×3 平均池化） |
| 小块嵌入 | 每个空间位置上得到一个 patch 向量，形成"正常小块"集合 | patch 感受野与步长 |
| 记忆库构建 | 贪心 k-中心核心集选择（`approx_greedy_coreset`, p=0.1）压缩正常小块 | 核心集选择的近似比与随机性 |
| 打分 | 查询小块的分数 = 到记忆库的**最近邻距离**；图像分数 = patch 分数的**最大值** | 图像分数是否用重加权（softmax 权重 × 距离） |
| 重加权 | 用最近的 s 个邻居做 softmax 加权，改善定位 | 重加权后**是否还是逐坐标单调**——这决定第 4 周的区间论证能不能直接套用 |
| 协议 | MVTec AD 上按类别报告 image AUROC 与 pixel AUROC（PRO 曲线） | 官方评测脚本用的是哪个指标定义 |

**一句话结论（也是本项目的地基）**：PatchCore 的"库"与"最近邻距离"都不是新东西；
本项目要问的是**压缩这个库之后，固定阈值下的二元报警是否还一致**。

**关键区分（必须写进你的笔记）**：
- 官方 PatchCore 的**重加权分数**不被 max-score 的区间证明覆盖；
- 我们自研的参考检测器命名要明确，例如 `max-score reference detector`（冻结特征 + 欧氏最近距离 + 最大 patch 分数）；
- 两者绝不能混在一张表里，也不能把前者的复现结果当成后者的验证。

## 4. 五个未决问题（A12 Phase 1 要求提交）

1. **压缩为什么会改变决策？** 丢掉参考点只会让最近邻距离**变大**，那么"变大"在什么条件下足以
   把一张原本 `s ≤ t` 的图推过阈值？它与"离阈值有多近"是什么关系？
2. **半径在真实特征空间里有多大？** 高维（D=384 或 1024）下，一个 cell 的半径与 cell 内点数、
   特征维度、以及核心集选择比例是什么关系？这直接决定 `U − L` 的宽度与升级率。
3. **从 max 换成 top-k 平均还成立吗？** 导师 handout 说逐坐标单调的固定 top-k 平均承认类似界限，
   但重加权不承认。为什么？单调性在聚合这一步具体要求什么？
4. **校准集只有 N 张正常图时，5% 分位数有多准？** 用顺序统计量/Wilson 区间估算一下：
   N=100 与 N=500 时，`t` 的抽样波动分别是多少？这决定"5% 名义误报"能支撑多强的结论。
5. **精确树的对照为什么不能直接比？** cover tree / ball tree 的查询复杂度依赖 doubling dimension
   等假设（[R10]）；在同一个库上，它的**内存**（树节点）与查询代价，与本方案的 `O(KD+K)` 存储
   到底怎么比才公平？
